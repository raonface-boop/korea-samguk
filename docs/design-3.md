# 3차: 화면 교체 (삼국지4 그림 + 삼국지3 명령 체계)

- 화면은 1672x941 고정 무대를 창 크기에 맞춰 통째로 확대·축소(비율 유지, 남는 곳은 검은 여백).
- 왼쪽 지도(1005x941), 오른쪽 패널(667x941, public/ui/panel.jpg 그림 그대로). 좌표는 src/data/ui_layout.json.
- 패널의 버튼 칸에는 글자 그림(public/ui/letters/단어.png)을 얹는다. 세로 칸은 v_단어.png. 바뀌는 글자는 Jua 글꼴 + 짙은 갈색 테두리(#3B1E0C) + 그림자.
- 명령 체계는 src/data/commands.json. 맨 위 보기 4칸, 큰 칸 6개(나라 운영), 아래 줄 7칸(성 명령), 성 그림 옆 세로 5칸.
- 지도는 계절별 4장(public/map/season/*.jpg, 길이 그림 안에 그려져 있음). 성·깃발·다리·고개·배는 public/sprites.
- 길 경로는 src/data/routes.json(지형을 따라 굽은 점 목록). 부대는 이 점을 따라 이동해 그린다.
- 4차에서 만들 것: commands.json 의 action 이 todo 인 기능 전부(포로 2편식, 담당 상황표, 주막, 수련, 군사 참모, 본국·속령 방침, 3편 계략, 상인, 컴퓨터 성향).
